# Common Network Security Threats

## Objective

This project is part of the Oasis Infobyte Cyber Security Internship (OIBSIP).

The objective of this task is to research common network security threats, explain how they work, describe their real-world impact, and discuss effective mitigation strategies.

## Files Included

* `network_security_threats_report.md` – Detailed research report.
* `README.md` – Project overview.

## Topics Covered

* DoS and DDoS Attacks
* Man-in-the-Middle (MITM) Attacks
* IP Spoofing
* DNS Poisoning / DNS Spoofing

## Tools Used

* Markdown
* GitHub
* Online research from trusted cybersecurity resources
